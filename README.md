# Signalfiltering

Statistical machine learning is a subfield of artificial intelligence and data science that uses mathematical and statistical theories to build algorithms capable of learning from data and making predictions

Course: Statistical Machine Learning
Prerequisites: [Linear_Algebra, Multivariable_Calculus, Probability_Theory]
Environment: [Python, R]

Syllabus_Breakdown:
  Module_01: Statistical_Foundations
    - Probability_Spaces: [Random_Variables, Joint_Distributions, Conditional_Probability]
    - Parameter_Estimation: [Maximum_Likelihood_Estimation_MLE, Maximum_A_Posteriori_MAP]
    - Bayesian_Inference: [Prior_Distributions, Posterior_Distributions, Conjugate_Priors]
    - Hypothesis_Testing: [Null_Hypothesis, P_Values, Likelihood_Ratio_Tests]

  Module_02: Statistical_Learning_Theory
    - Generalization_Error: [Empirical_Risk_Minimization, True_Risk, Bias_Variance_Tradeoff]
    - Complexity_Measures: [VC_Dimension, Rademacher_Complexity]
    - Model_Selection: [Cross_Validation, AIC, BIC]

  Module_03: Supervised_Learning_Regression
    - Linear_Models: [Ordinary_Least_Squares_OLS, Generalized_Linear_Models]
    - Regularization: [Ridge_L2, Lasso_L1, Elastic_Net]
    - Non_Linear_Regression: [Splines, Kernel_Regression, Gaussian_Processes]

  Module_04: Supervised_Learning_Classification
    - Generative_Models: [Linear_Discriminant_Analysis_LDA, Naive_Bayes]
    - Discriminative_Models: [Logistic_Regression, Support_Vector_Machines_SVM]
    - Non_Parametric: [K_Nearest_Neighbors_KNN, Decision_Trees]
    - Ensembles: [Random_Forests, Gradient_Boosting_Machines_GBM, AdaBoost]

  Module_05: Unsupervised_Learning
    - Clustering: [K_Means, Hierarchical_Clustering, DBSCAN]
    - Latent_Variable_Models: [Gaussian_Mixture_Models_GMM, Expectation_Maximization_EM]
    - Dimensionality_Reduction: [Principal_Component_Analysis_PCA, Kernel_PCA, t_SNE]

  Module_06: Optimization_Techniques
    - Convex_Optimization: [Convex_Sets, Convex_Functions, Duality_Theory]
    - First_Order_Methods: [Gradient_Descent, Stochastic_Gradient_Descent_SGD]
    - Constrained_Optimization: [Lagrange_Multipliers, KKT_Conditions]
